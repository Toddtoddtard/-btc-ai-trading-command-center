# BTC AI Trading Command Center

A paper-trading-first Bitcoin prediction dashboard prototype.

## Run locally
1. Install Python 3.10+.
2. In this folder run:
   `pip install -r requirements.txt`
3. Run:
   `streamlit run app.py`

The dashboard is designed around specialist AIs that communicate with a master prediction layer. The included demo mode uses clearly labeled simulated inputs so it is safe to explore before connecting real market data.
